# 棋盘合成小游戏开发需求文档

1. ## 项目概述

### 项目名称

Merge Board Game（暂定）

### 项目类型

2D休闲合成类小游戏。

参考玩法：

- Merge Mansion

- Travel Town

- 梦幻家园类合成玩法

### 开发目标

开发一个本地运行的单机版棋盘合成小游戏。

运行环境：

- Windows桌面

- Cocos Creator预览环境

  不需要：

- 后端服务器

- 用户系统

- 网络同步

- 排行榜

- 支付

- 广告

1. # 核心玩法概述

   玩家通过：

   1. 点击发射器生成物品

   2. 将物品拖动到棋盘

   3. 两个相同物品合成升级

   4. 完成订单获得金币

   5. 使用金币作为游戏资源

      核心循环：

      ```plaintext
      发射物品
      
      ↓
      
      放入棋盘
      
      ↓
      
      合成升级
      
      ↓
      
      满足订单
      
      ↓
      
      获得金币
      
      ↓
      
      继续合成
      ```

      ---

1. # 订单生成规则

   订单来源：

   固定配置。

   例如：

   order.json

   ```json
   {
   "id":1,
   
   "items":[
    "towel_lv3",
    "glass_lv2"
   ],
   
   "reward":300
   }
   ```

   规则：

   - 随机生成

   - 当前5个订单不能重复

2. # 自动订单优先级

   当棋盘生成新物品：

   检测：

   ```plaintext
   new Item
   |
   遍历订单
   |
   是否需要该物品
   ```

   如果命中：

   该订单自动移动到第一个位置。

   例如：

   之前：

   ```plaintext
   A B C D E
   ```

   命中C：

   ```plaintext
   C A B D E
   ```
